PROYECTO: K-World-Experience
EVIDENCIA: GA3-220501096-AA2-EV02.

DESCRIPCIÓN
K-World-Experience es una aplicación web sobre diferentes destinos turísticos
de Corea del Sur. Permite explorar las ciudades de Seúl, Busan y Jeju,
ver diferentes destinos, filtrarlos por categorías, consultar sus detalles
y agregarlos o quitarlos de favoritos.

TECNOLOGÍAS UTILIZADAS
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8.

ESTRUCTURA DEL PROYECTO
- index.html: contiene la estructura principal de la página.
- styles.css: contiene los estilos y el diseño responsive.
- app.js: contiene las funciones e interacciones de la página.
- assets/: contiene las imágenes y recursos utilizados en el proyecto.
- pruebas/: contiene las evidencias de las pruebas realizadas.

CÓMO EJECUTAR LA APLICACIÓN
1. Descargar o clonar el proyecto.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir el archivo index.html en el navegador.
4. También se puede utilizar Live Server desde Visual Studio Code.

PUBLICACIÓN EN GITHUB
El proyecto fue subido a GitHub para probar su funcionamiento como una
página web y poder visualizar la aplicación directamente desde el navegador
mediante GitHub Pages.

FUNCIONALIDADES
- Explorar las ciudades de Seúl, Busan y Jeju.
- Ver diferentes destinos turísticos.
- Filtrar los destinos por categoría.
- Consultar los detalles de cada destino.
- Agregar destinos a favoritos.
- Quitar destinos de favoritos.
- Evitar destinos favoritos repetidos.
- Diseño responsive.
- Navegación mediante teclado.

PRUEBAS
Las pruebas realizadas y sus evidencias se encuentran en la carpeta
"pruebas".

RESULTADO
La aplicación permite explorar diferentes destinos turísticos de Corea del
Sur, utilizar filtros, consultar información y gestionar favoritos desde
una interfaz web responsive.
